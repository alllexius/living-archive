# A Living Archive — how this works

No frameworks, no build step, no font
downloads, no dependencies of any kind. 

## The files
- `index.html` — the frame
- `archive.html` — studies
- `field-notes.html` — journal entries + recordings - one at a time
- `field-drift.html` - journal entries + recordings - as a sphere
- `contact.html` — email and Are.na
- `style.css` — visual decisions
- `cursor.js` — the cursor
- `interference.js` — behavior of button and background
- `interference.css` — appearance of button and background
- `assets/` — images, audio, and video
- `room-color.html` — The Room: the screen as the room's light
- `room-settings.js` — every adjustable value of The Room, in plain words. The only Room file to edit.
- `room-color.js` — how The Room works (not for tuning)
- `room-color.css` — appearance of The Room

To tune The Room by eye: open `room-color.html?tune`, press T to show or hide the panel.
